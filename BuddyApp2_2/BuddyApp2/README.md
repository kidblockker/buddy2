# Buddy v2 — JARVIS-Style AI Companion

## What's fixed in v2
- ✅ NO more broken mic loop (open/close every second)  
- ✅ HOLD mic button to speak → release → Buddy replies
- ✅ Buddy speaks proactively every 8-15 min (news, tech, health, wisdom, warnings)
- ✅ Every proactive update appears in chat with a colored category badge
- ✅ "Hey Buddy" wake word still works in background
- ✅ Clean JARVIS-style waveform (idle/listen/think/speak states)

## Setup (3 steps)
1. Open BuddyApp2 folder in Android Studio
2. Download gradle-wrapper.jar when Android Studio prompts (one click)
3. Run app → Settings → paste Anthropic API key from console.anthropic.com

## How to use
| Action | What happens |
|---|---|
| **Hold mic button** | Buddy listens while you hold |
| **Release mic** | Buddy processes + speaks reply |
| **Say "Hey Buddy"** | Activates mic from anywhere |
| **Type + send** | Text conversation |
| **Camera icon** | Show camera → tap "Ask Buddy" |
| **Every 8-15 min** | Buddy shares a news/fact/insight |
| **Long press waveform** | Clear chat |

## Proactive update categories
- 🟠 NEWS — World events with Buddy's take
- 🔵 TECH — AI, startups, technology  
- 🟣 SCIENCE — Research, space, discoveries
- 🟢 HEALTH — Evidence-based wellness tips
- 🟡 PRODUCTIVITY — Focus and efficiency
- 🩷 WISDOM — Life insights
- 🔴 WARNING — Risks and blind spots
- 🟩 FINANCE — Money and economy
